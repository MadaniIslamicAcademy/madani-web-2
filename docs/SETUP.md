# Setup Guide

## Requirements

• Docker Desktop with Docker Compose
• Git
• A modern browser

Node.js and Python are only required when running services without Docker.

## Local installation

1. Clone the repository.
2. Copy `.env.example` to `.env`.
3. Generate a secret key.
4. Generate a Fernet encryption key.
5. Set a strong bootstrap administrator password.
6. Run `docker compose up --build`.
7. Open `http://localhost:3000`.

Generate a Fernet key with Python:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

## First administrator

At API startup, the backend creates the bootstrap administrator only when no user exists. Change the bootstrap password immediately after the first login.

## Mock publishing

Leave `SOCIAL_PUBLISH_MODE=mock` during development. Create a mock connection from the Connections page. Scheduled publishing, retries and reports will work without sending content outside the system.

## Real provider setup

Read `docs/SOCIAL_INTEGRATIONS.md`. Each provider requires its own developer application, permissions and account authorization.

## Database migrations

Run migrations after every model update.

```bash
cd apps/api
alembic revision --autogenerate -m "describe change"
alembic upgrade head
```

Always review an autogenerated migration before running it in production.

## Production checklist

• Use PostgreSQL and Redis managed services.
• Set `COOKIE_SECURE=true`.
• Use HTTPS only.
• Change all bootstrap and webhook secrets.
• Set exact allowed frontend origins.
• Keep provider credentials in the hosting secret manager.
• Run one API instance and separate worker and beat services.
• Configure database backups.
• Enable error monitoring.
• Test in mock mode before enabling a real connection.


## Media storage

Local and Docker development store uploaded media in the `uploads` volume. For production, replace `app/services/storage.py` with an S3 compatible adapter so media survives service restarts and is available to social platforms through a public HTTPS URL.
